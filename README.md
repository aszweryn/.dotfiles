# .dotfiles

Personal configuration files for Linux/macOS:

- `neovim/`: Neovim configuration (`lazy.nvim`, LSP via Mason, Treesitter, Telescope, Harpoon, Neogit, Catppuccin)
- `tmux.conf`: Tmux configuration with TPM, Catppuccin Mocha, and vim-tmux navigation
- `kitty/kitty.conf`: Kitty terminal configuration
- `alacritty.toml`: Alacritty terminal configuration
- `.zshrc`: Zsh configuration with Oh My Zsh, toolchains, and lazy-loaded NVM
- `.gitconfig`: Git user and editor configuration
- `bluetooth/bt.sh`: Bluetooth resume helper script
